description: Plan the coming week's Media Marketing Agent posts
---

Read `agents/media-marketing/CLAUDE.md`, `agents/media-marketing/strategy.md`,
`agents/media-marketing/content/pillars.md`,
`agents/media-marketing/content/hook-bank.md`, and
`agents/media-marketing/content/calendar.md` before doing anything else.

Then:

1. **Ask first, don't invent.** Ask Nolan, briefly, what actually
   happened / is scheduled this coming week — training, sales-day
   moments, anything Doctrine-worthy. Never assume or fabricate an
   activity (rule 1 in `CLAUDE.md`). If he doesn't answer in detail,
   work with whatever he gives you rather than padding it out.
2. **Check the floor/ceiling status.** Ask which mode the past week ran
   in. If 3+ floor days happened in a row, apply the cadence-reduction
   rule (`CLAUDE.md` rule 6) — plan fewer posts, don't demand catch-up.
3. **Check performance data.** If `logs/media-marketing/posts/` has
   enough entries (rule of thumb: 5+), read the most recent `/review`
   output or compute pillar performance directly, and weight pillar
   assignment toward what's actually working — not the fixed 40/25/25/10
   split in `content/pillars.md`, which is a cold-start default only.
4. **Assign each post:** pillar, a hook (pull from
   `content/hook-bank.md` where it fits, mark it `used` with today's
   date when assigned; generate new ones via the same logic as `/hook`
   if nothing in the bank fits), format, rough length, one-line shot
   list, and CTA (the DM keyword / email-capture link per
   `knowledge/funnel.md` — no product CTA ever, per rule 3).
5. **Write the result** into `agents/media-marketing/content/calendar.md`
   under the current week, replacing the placeholder "generated by
   `/plan-week`" note for that week.
6. **Output to Nolan**: a short, phone-readable list — day, pillar, hook
   line, one-line shot note. No preamble, no restating the rules back to
   him.

If nothing real happened/is scheduled for a given pillar this week, leave
that slot as a rest day or a Stories-only day rather than inventing
content for it — say so plainly.
